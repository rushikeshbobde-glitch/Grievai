## 🏛️ Executive Overview

**GrievAI** is a production-grade, hackathon-ready civic intelligence web platform that transforms public grievance redressal through explainable NLP triage, automated urgency prioritization, deterministic department routing, duplicate complaint detection, and verified resolution workflows backed by photographic evidence.

---

## 🌟 Core Features & Capabilities

### 1. Citizen Experience
- **Smart Grievance Submission**: Submit complaints with automatic GPS map pin selection (Leaflet / OpenStreetMap) and photo attachments.
- **Real-Time AI Preview**: Live NLP triage as you type — predicting category, priority, sentiment, summary, and municipal action recommendation.
- **Duplicate Prevention Warning**: Real-time alerts if similar grievances exist in geographic proximity.
- **4-Stage Tracking Timeline**: Real-time tracking from `Submitted` ➔ `Assigned` ➔ `In Progress` ➔ `Resolved`.
- **Verified Evidence & Citizen Rating**: View officer photographic proof and submit 1–5 star ratings and feedback.
- **In-App Notification Center**: Instant alerts on status changes and resolution requests.

### 2. Admin Command Center
- **Executive KPI Analytics**: Total complaints, triage queues, average resolution times, and real database aggregations.
- **Interactive Recharts Visualizations**: Category distribution donut charts, 14-day submission vs resolution area trends, and geographic hotspot map overlays.
- **Human-in-the-Loop Triage**: Review AI confidence and trigger words, override categories or priorities, and assign field officers.
- **Duplicate AI Manager**: Side-by-side complaint comparison with TF-IDF cosine similarity % and Haversine distance filters.
- **Department & Officer Directory**: Manage jurisdictions, officer badge assignments, and availability.
- **CSV Report Exporter**: Download filtered municipal records for audits and reviews.

### 3. Field Officer Portal
- **Urgency-Sorted Task Queue**: High-priority tasks displayed on top for rapid municipal intervention.
- **SOP Action Guidance**: Actionable resolution templates generated by the AI engine.
- **Status Lifecycle Control**: Progress tasks to `In Progress` and upload resolution photo proof with remarks.
- **Resolution History**: Performance logs of completed tasks.

## 🧠 Explainable AI / NLP Engine Architecture

| Component | Technique | Functionality |
|---|---|---|
| **Category Classification** | Sublinear TF-IDF + Logistic Regression | Categorizes into 8 civic departments with confidence scores |
| **Priority Prediction** | Explainable Urgency Scorer | Factors hazard keywords, temporal duration cues, and citizen distress |
| **Sentiment Analysis** | VADER Lexicon with Civic Enhancements | Quantifies citizen distress tone (`Positive`, `Neutral`, `Negative`) |
| **Department Routing** | Deterministic Civic Registry | Routes predicted category to municipal department |
| **Extractive Summarization** | Lexical Syntactic Filter | Generates a clean 1-line problem summary |
| **Duplicate Detection** | Cosine Similarity + Haversine Distance | Flags duplicate complaints within configurable geo-radius |

## ⚡ Quickstart & Local Setup

### 1. Backend Setup

```bash
cd backend

# Create virtual environment
python -m venv .venv

# Activate virtual environment
# Windows:
.\.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Start FastAPI server
uvicorn app.main:app --port 8000 --reload
```

FastAPI OpenAPI interactive docs will be available at: `http://localhost:8000/docs`

### 2. Frontend Setup

```bash
cd frontend

# Install npm dependencies
npm install

# Start Vite development server
npm run dev
```

Frontend application will be live at: `http://localhost:5173`
